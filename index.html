Device Compatibility Note

Android (Chrome / Edge / Brave): Full screen mirroring works natively right inside the browser.

iPhone / iPad (iOS Safari): Apple blocks browser screen capture (getDisplayMedia) on iOS. You can still use Rear/Front Camera mode here, or use AirPlay / USB cable for full iOS screen mirroring.
